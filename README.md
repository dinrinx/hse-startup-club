# Стартап Клуб ВШЭ — фирменный стиль для Claude

Плагин с дизайн-системой клуба и картой типовых слайдов. Ставится один раз, после чего Клод собирает презентации участников в едином фирменном виде: питч на 5 слайдов, питч-дек на 11 или большую презентацию на 16–18.

## Установка в Claude Code

```
/plugin marketplace add 57lol/hse-startup-club
/plugin install startup-club-deck@hse-startup-club
```

Дальше просто: «сделай питч-дек про такой-то проект».

## Если Claude Code нет

Скачайте `startup-club-deck.zip` из релизов и загрузите его в настройках Claude — Settings → Capabilities → Skills.

## Что внутри

| Файл | Что это |
| --- | --- |
| `skills/startup-club-deck/SKILL.md` | порядок работы и правила, которые нельзя нарушать |
| `references/brandbook.md` | бренд-бук: голос, фирменные приёмы, цвет, шрифт, сетка |
| `references/slides.md` | карта слайдов: какой слайд за что отвечает, три сборки под формат |
| `references/tokens.json` | цвета, шрифты, отступы и скругления машиночитаемо |
| `references/layouts.html` | три эталонных слайда разметкой |

Дизайн-система собрана по публичным материалам канала [@hsestartupclub](https://t.me/hsestartupclub): цвета и геометрия сняты с реальных макетов, не придуманы. Векторный логотип в комплект не входит — в слайдах он собирается из фигур.
